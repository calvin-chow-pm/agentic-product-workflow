# Data notification and learning task

Use `check_inbox` to observe a request response; if absent, report pending. On arrival, report the request id, source and limitations to the product discussion. You cannot query raw data through this surface.

Stage a concise lesson, but do not approve or promote it. After human review and trusted context refresh, read the new context pack. For a subsequent task, explicitly apply the approved lesson text and cite its id. Distinguish the prepared task prompt from actual completed reasoning.
